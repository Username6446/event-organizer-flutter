# Eventory — органайзер невеликих подій

Flutter Web застосунок для планування невеликих подій: дні народження,
корпоративи, пікніки. Список гостей, чек-лист завдань та нагадування.

Проєкт виконується в межах курсу «Кросплатформне програмування»
(Національний університет «Львівська політехніка», варіант 14).

## Стан

**Лабораторна робота №3** — інтерфейс без бізнес-логіки (hardcoded дані):

- екран входу / реєстрації (перемикання режимів);
- відновлення пароля в 3 кроки (email → код → новий пароль);
- головна сторінка (дашборд) зі статистикою та картками подій;
- профіль користувача зі зміною пароля та індикатором надійності;
- адаптивна навігація: `NavigationRail` на широких екранах, `NavigationBar` на мобільних.

## Запуск

```bash
flutter pub get
flutter run -d chrome
```

## Структура

```
lib/
├── main.dart                 # точка входу
├── app.dart                  # MaterialApp, тема, стартовий екран
├── core/                     # спільне для всього застосунку
│   ├── data/                 # mock-дані
│   ├── theme/                # кольори, відступи, тема
│   ├── utils/                # форматування дат, SnackBar
│   └── widgets/              # перевикористовувані віджети
├── models/                   # моделі даних
└── features/                 # екрани, згруповані за функціями
    ├── auth/                 # вхід, реєстрація, відновлення пароля
    ├── shell/                # оболонка з навігацією
    ├── home/                 # дашборд
    ├── profile/              # профіль
    └── placeholder/          # заглушка для майбутніх розділів
```

Сторонні пакети не використовуються — лише Flutter SDK.
